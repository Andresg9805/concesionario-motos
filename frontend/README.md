# Frontend (Angular)

Aquí va el proyecto Angular de la página. Lo crea Andrés en el Sprint 1 con:

```
ng new concesionario-front --directory . --routing --style=scss
```

El frontend consume la API del backend en `http://localhost:8000`. El backend ya tiene habilitado CORS para `http://localhost:4200`, que es donde corre Angular con `ng serve`.
